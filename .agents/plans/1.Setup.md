## AGENTS.md

Maintainer contract (written in-repo):

1. **API** — dual surface (methods + top-level funcs); fallible constructors/solvers return `error`; `Must*` counterparts; nil checks on pointer args; math stays MATHable.
2. **Errors** — exported; no panics on invalid/singular numeric input for constructors and singular solvers.
3. **Tests** — table-driven `testCase`; RFC 2119 only in case names / `t.Run`; rapid property tests (+ optional `MakeFuzz`); fuzzing asserts invariants.
4. **Documentation** — per-package `doc.go`; exported docs; GFM LaTeX in Markdown; Unicode/preformatted math in Go comments.
5. **Examples** — runnable `Example*` preferred; may defer.
6. **Self-maintenance** — tools/skills for repeated work; Makefile for human repetition; how-tos with preconditions and verifiable steps.
7. **Sketch** — non-gospel package tree; update as design evolves.
