# Execution Plan: Surface-Driven Implementation & Reviews

This plan governs the implementation, verification, mathematical review, policy review, and commit sequence for `github.com/stephen-mcelhose/markov` against the canonical surface graph (`docs/surface/surface.jsonld` and `docs/architecture.md`).

## Commit & Work Group Sequence (DAG Order)

Per `AGENTS.md` (DAG Order List), work is divided into 6 commits:

1. **Commit 1 — Architecture, Surface Graph & Enforcement Tooling**
   - `AGENTS.md`, `Makefile`, `LICENSE`, `docs/architecture.md`, `docs/invariants/invariants.md`, `docs/surface/{context.jsonld,surface.shacl.ttl,surface.jsonld,surface.md}`, `docs/wiki/`, `.agents/plans/{2.Surface.md,3.Execution.md}`, `tools/surface/`, `tools/testspec/`.
   - Tooling upgrade: `tools/surface --verify-ast [pkg...]` parses implemented Go packages via `go/ast` and verifies:
     - `doc.go` exists and has a package doc comment (`AGENTS.md` Documentation #1).
     - Every symbol in `surface.jsonld` for that package exists in the expected `.go` file with the exact normalized Go signature.
     - Every exported identifier in the package has a Go doc comment without raw LaTeX backslashes (`AGENTS.md` Documentation #2 & #4).
     - Test files do not use RFC 2119 keywords in `func Test*` names (`AGENTS.md` Tests #5).

2. **Commit 2 — Layer 1: Core Primitives (`package markov`)**
   - Files: `doc.go`, `errors.go`, `kernel.go`, `kernel_test.go`, `distribution.go`, `distribution_test.go`, `partition.go`, `partition_test.go`, `known_unknowns.list`.
   - Resolve `known_unknowns.list` items and document choices in `doc.go`.

3. **Commit 3 — Layer 2: Exact Dynamics & Structural Solvers (`package solve`)**
   - Files: `solve/doc.go`, `solve/classes.go`, `solve/stationary.go`, `solve/fundamental.go`, `solve/mfpt.go`, `solve/entropy.go`, `solve/*_test.go`, `solve/known_unknowns.list`.
